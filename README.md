# Python 自学教程 · 一条线走到底

一套为零基础自学者设计的 Python 教程：**41 课、5 个阶段、123 道选择题 + 41 道动手编程题**，从第一行 `print` 一路学到 pandas 数据处理与网络爬虫。没有需要注册的账号，没有要装的软件——打开就能学，写完代码当场判定对错。

## 下载版（HTML 空间版）

浅色暖纸设计，和网站版同一套课程内容，打包成**一个 HTML 文件**：

1. 在本仓库点开 **`python-space.html`**，点右上角的下载按钮（或在仓库主页点绿色的 `Code` → `Download ZIP` 把整个项目下载下来）；
2. 把文件放到任意文件夹，**双击即可用浏览器打开**，不需要安装任何东西；
3. 学习进度保存在你自己的浏览器里，关掉重开不会丢。

> 小提示：动手题的代码判定需要在浏览器里加载 Python 运行环境（Pyodide），首次打开某一课的动手题时会联网加载一次（约数秒）。看课文、做选择题、看代码演示不需要这一步。

**专业方向可切换**：本教程的应用场景默认按**会计**方向编写（账本、报表等例子）。不是会计专业的同学不用担心——页面顶部的「专业」切换（下载版在设置页与首次打开的选择卡里）可以换成**通用**方向，阶段名、标题与讲解里的场景表述会换成通用数据场景；核心代码与练习完全相同。会计方向是默认与完整保留的版本，不会被删减。

## 使用教程

1. **按路线学**：从第 1 课开始，一课里依次是「讲解 → 代码演示 → 选择题 → 动手写代码」。
2. **代码演示**：每课开头都有一段自动播放的演示，代码会像真人打字一样逐字出现、运行结果逐行给出，先看懂再动手。
3. **选择题**：点选项立刻判对错，附一句为什么。
4. **动手题**：在课内编辑器里写真正的 Python，点运行**当场判定**。判定不苛刻：内容对、没语法错误就通过（多打印的行、全半角、空白差异都不扣）；写错了会直接告诉你最可能的原因（全角符号、缩进、漏冒号、变量名打错之类）。
5. **AI 导师（可选）**：每课配有 AI 讲解入口，填入你自己的 AI API Key 即可提问（支持 OpenAI 兼容接口）。Key 只保存在你自己的浏览器里，不会上传到任何服务器。不填也能正常学完全部课程。
6. **进度与成就**：完成课程积累 XP、点亮阶段徽章，进度只存在本地浏览器。

## 安装教程

**使用者：不需要安装。** 在线版打开网址就用；下载版双击 HTML 就用。

**想自己部署一份（Fork 本仓库）：**

1. Fork 或克隆本仓库；
2. 启用 GitHub Pages：仓库 `Settings` → `Pages` → `Source` 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存；
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即是网站版。

**本地预览：**

```bash
git clone https://github.com/HobartSZE/python-tutorial.git
cd python-tutorial
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
